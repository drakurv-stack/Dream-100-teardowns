# Dream 100 Teardowns

Auditing 200 company websites. Shipping free fixes. In public.

## The play

1. Pick a company from the Dream 200 list.
2. Audit their site: performance, accessibility, SEO, broken stuff, mobile.
3. Fix the highest-impact issue with real code.
4. Send the teardown + fix to the company. Free. No strings attached.
5. Document it here.
